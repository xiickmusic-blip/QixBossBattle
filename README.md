# RAID QIX

Electron + Steam P2P QIX boss raid prototype.

## v0.5.0

- arena logical scene expanded from 960 x 540 to 1440 x 810
- play field expanded to 1320 x 670, roughly 1.5x wider/taller than v0.4
- Boss 3 GRID SERAPH no longer teleports
  - slowly drifts through the arena
  - four slow rotating lasers remain active
- Boss 4 GRAVITY MAW shockwave ring removed
  - gravity wells remain
  - now fires a dodgeable 18-way radial projectile burst
- new Boss 5: ORACLE ENGINE
  - uses reusable MMO-style circular AoE attack telegraphs
  - warning circle appears first
  - after the warning expires, players inside the circle take damage
- reusable `spawnTelegraphCircle(x, y, radius, options)` system can be used by future bosses
- AoE telegraph state is generated by the Steam lobby host and synchronized to clients
- PSX pixel buffer expanded to 480 x 270 for the larger logical scene
- all eight cores remain mandatory for boss defeat

## Windows

- `start.bat` installs dependencies if needed, then runs `npm start`
- `build.bat` installs dependencies if needed, then runs `npm run build`
- portable build output: `dist/`
